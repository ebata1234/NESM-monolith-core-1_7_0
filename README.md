# NESM モノリスコア版 (1.20.1 / Forge 47) v1.7.0

StockiesLad/NESM のソースに「モノリスコア」(旧: モノリスコア) を追加した改造版です。
MOD ID は元のまま (`nightmareesm`) なので、**今の NESM の jar と入れ替えて使います**
(両方 mods フォルダに入れると重複エラーになります)。

## 追加されるもの
- ブロック「モノリスコア」(見た目はロードストーン。独立した別ブロックなので、元からあるロードストーンには効果なし。発光しません)
- レシピ (定形):
  ```
  . 金 .
  金 ダイヤ 金
  鉄 鉄ブロック 鉄
  ```
  (金インゴット3 / ダイヤ1 / 鉄ブロック1 / 鉄インゴット2)
- クリエイティブタブ「機能ブロック」にも入っています

## 効果
1. モノリスコアがあるチャンクでは、NESMのモブによるブロックの設置・破壊が止まります。
   ゾンビの採掘 (前・上・下)、丸石の柱積み、橋かけ、TNT設置、火つけ、クモの巣。
2. クリーパーなどの爆発、プレイヤーの建築・破壊は今までどおりです。
3. 世界にあるモノリスコア1個につき、全プレイヤーの L2Hostility 追加難易度 (`l2hostility:extra_difficulty`) が +5。
   全ディメンションの合計で、置く・壊す・爆発で壊れる、のたびに即反映されます。
   すでに湧いているモブのレベルは変わらず、新しく湧くモブから反映されます。

## 設定 (config/esm-config.toml、初回起動後に作られます)
- `protectionLanternRadius` : 0 = モノリスコアのいるチャンクのみ (初期値) / 1 = 3x3 チャンク / 2 = 5x5 チャンク
- `protectionLanternDifficulty` : 1個あたりの難易度 (初期値 5、0で無効)

## 動作確認のしかた
- `/give @s nightmareesm:protection_lantern` で入手
- `/attribute @s l2hostility:extra_difficulty get` : 置くと 5.0、2個で 10.0、壊すと戻る

## v1.2.0 で追加: ナパームクリーパー
クリーパーが爆発すると、爆発地点の周囲の地面に火がまき散らされ、爆発に巻き込まれた生き物は5秒間燃えます。
爆発の威力や範囲は変わりません。mobGriefing が false のときは火も出ません。
- `creeperNapalm` : true/false (初期値 true)
- `creeperNapalmRadius` : 火をまく範囲(ブロック) (初期値 6)
- `creeperNapalmFires` : 1回の爆発でまく火の数 (初期値 25)
- `creeperNapalmIgnitesEntities` : 巻き込まれた生き物に着火 (初期値 true)
※ 爆発由来なので、モノリスコアの保護範囲内でも火は出ます。

## 寝られるようにする
config/esm-config.toml の `allowSleep = false` を `true` にして、ゲームを再起動します。


## v1.3.0 の注意
ブロックIDを `protection_lantern` から `monolith_core` に変えたため、旧版で置いた保護のランタンはワールドから消えます (開発中ワールド向け)。
睡眠: `allowsleep = true` でも、ベッドの周囲8x5x8に敵対モブがいるとバニラ仕様で眠れません。

## v1.4.0 で追加: レベルに応じた移動速度 (L2Hostility)
モブのL2Hostilityレベルに応じて、特性とは別に基礎移動速度が上がります。
- 通常のモブ: Lv0で+0% → Lv100で+75% (直線的に上昇、Lv100が上限)
- ゾンビ・スケルトン: なめらかな曲線で Lv50=+75% / Lv100=+100% / Lv200=+150% (Lv200が上限)
  (目安: Lv10=+19% / Lv25=+45% / Lv75=+89% / Lv150=+125%)
- 設定: `mobSpeedScaling` (ON/OFF), `mobSpeedScalingMaxBonus` (0.75), `mobSpeedScalingMaxLevel` (100),
  `mobSpeedScalingFastCurveMobs` (初期値 `minecraft:zombie,minecraft:skeleton`。ハスク等を足したいときはここへ追記)
- L2Hostilityが無い場合は何も起きません。1秒ごとに再計算され、セーブには保存されません。
- 海での加速 (AugmentOceanSpeed) が全速度補正を消していたため、海の補正だけを消すよう修正しました。


## v1.5.0 の変更
- **ブロック破壊を元のNESMの挙動に戻した**: ゾンビが掘ったブロックはドロップし、破壊の演出も出ます。モノリスコアの保護チャンクの中だけ、これまでどおり壊れません。
- **モノリスコアの名前を水色で表示**。
- **モノリスゴーグル** (ヘルメット): 頭に装備している間、モノリスコアが保護するチャンクの境界が半透明の柱と枠線で見えます。
  レシピ: 革 鉄インゴット 革 / ガラス板 ダイヤ ガラス板 (上段 LIL、下段 GDG)。クリエイティブタブ「機能ブロック」にも入っています。
  保護範囲 (`protectionLanternRadius`) の外周だけを描きます。サーバー側のチャンク情報を1秒ごとに送ります。
- **エンダーパールを持つゾンビ** (`zombieEnderPearl*`): 約10%のゾンビが左手にパールを持って湧き、プレイヤーが10〜32ブロック離れていて視線が通るときに投げて、着地点へワープします。1体につき1個、使い切り。未使用のまま倒すとドロップしません (`zombieEnderPearlDropChance` で変更可)。
- **後ろに跳ぶスケルトン** (`skeletonEvade*`): プレイヤーが5ブロック以内に近づくと、0.5秒ごとに15%の確率で大きく後ろ・横へ跳びます。1回の回避は基本1〜2連続、3連続は10%。回避が終わるごとに10〜15秒のクールタイム。
- **索敵範囲の下限** (`mobFollowRange`, `mobFollowRangeMin`): 敵対モブ (`Enemy`) の初期の索敵範囲が64未満なら64にします。すでに64以上のモブは変えません。

## v1.6.0 の変更 (v1.5.0 の AI 修正版ソースが土台)
- **天然ブロックはドロップしない**: モブが壊したブロックが、設定 `naturalBlockList` (初期値: 石・ネザーの石・土・砂・テラコッタ・鉱石・ネザーラック系の菌糸・雪・砂利・粘土・泥・エンドストーン・砂岩・氷・ソウルサンド・マグマブロック・黒曜石) に当てはまればドロップなし (`naturalBlockNoDrop`)。
  丸石・木材・レンガなど加工ブロックは今までどおりドロップします。リストは `#タグ` か ブロックID をカンマ区切りで編集できます。
- **モブが置いたブロックもドロップしない** (`mobPlacedBlockNoDrop`): 柱・橋の丸石の座標をワールドに記録 (最新2万個/ディメンション)。プレイヤーがその場所を壊す・置くと記録は消えるので、プレイヤーの建築は対象外です。
- **ピグリンなどのゾンビ化** (`zombieLikeMobs`, 初期値 `minecraft:piglin,minecraft:piglin_brute`): リストのモブが、ゾンビと同じ掘る・積む・橋をかける・TNT・火つけをし、プレイヤーへ向かって攻撃します (金装備でも襲います)。
  ピグリンは頭脳AIで動くため、NESMが決めたターゲットを頭脳にも毎ティック書き込んでいます。オーバーワールドでゾンビピグリンに変わらないようにもします (`zombieLikeNoZombification`)。
- **スケルトンの剣の構え** (`skeletonSword*`): プレイヤーが5ブロック以内で弓→剣に持ち替え (弓は左手)、プレイヤーを向いたまま後退し、届く距離なら斬ります。10ブロック以上離れたら弓に戻って撃ちます。
  剣は鉄が最低で、L2Hostilityのレベル50以上でダイヤ、100以上でネザライト。鋭さ=レベル/25 (最大5)、レベル60以上で ノックバックI、80以上で 火属性I。剣はドロップしません。
  後退の速さは `skeletonSwordRetreatFactor` (移動速度属性 × この値) で調整できます。

## v1.6.1 の変更 (負荷・ログ・不具合の洗い出し)
- ログ: 名前が ICBM のクリーパーが毎ティック INFO ログを出していたのを削除。ジョッキー出現ログは debug に下げた。(ブロック破壊のたびに出ていたログは、AI修正版ですでに削除済み)
- ターゲット探索の負荷: NESMはほぼ全モブに対して毎ティック「全プレイヤー+周囲の村人」を探索し、さらに名前リストの文字列比較をしていた。探索を1モブあたり0.5秒に1回に変更し、名前リストの判定はモブの種類ごとに結果を保存するようにした。
- 最寄りのプレイヤーを選ぶ処理のバグ修正: 複数人プレイで「一番近い人」ではなく「リストの先頭の人」を狙うことがあった。別ディメンションのプレイヤーやスペクテイターも候補に入っていたので除外。
- 海上加速 (AugmentOceanSpeed): 水中にいる間、毎ティック「+200%」の補正を新規追加していて、無限に重なっていた (速度の暴走と、補正リスト肥大による負荷)。1回だけ付ける形に修正。
- siegeWhitelist: `zombie_villager` や `zombified_piglin` のようにアンダースコア入りの名前が表示名 ("zombie villager") と一致せず、リストに書いても襲撃対象にならなかった。IDでも一致するようにした。
- レベル速度とスケルトンの回避: 敵対モブ・スケルトンだけを先に絞り込むようにして、無関係なモブ (牛や村人など) での無駄な処理を削除。

## v1.7.0 の変更 (ゾンビの平面移動 / 視線なし感知 / クリーパー / スケルトン)
**注意: このバージョンはAIの環境でビルドも実機確認もできていません (構文チェックのみ)。** コンパイルエラーや、実際の挙動が意図と違う箇所があるかもしれません。GitHub Actions のビルド結果と、ゲーム内の様子を教えてください。

### ゾンビ(ピグリンなど `zombieLikeMobs` も同じ): 平面方向の近づき方
調べて分かった「鈍かった原因」と、その直し方です。
- 水平の掘り (`MobDig`) が、3択の乱数サイクルのうち1/3の間隔でしか動いていなかった → **毎回の掘りの間隔 (`entityDigDelay`) で動く**ようにした。上・下掘りは今までどおり順番に動く。
- 掘った直後の腕振り (`swinging`) の判定が、次の掘りを約6ティック止めていた → 判定を外した。
- 掘る向きが「モブが向いている向き」で決まっていた → **標的がいる方向** (長い軸を先、横にずれていれば次にもう一方の軸) に変えた。壁に阻まれて経路がなくても、正しい向きに掘る。
- 橋かけ (`MobBuildBridge`) は、標的との水平距離が4ブロック以上のときだけ動いていた (3ブロック以内の同じ高さの隙間は、誰も処理していなかった) → **距離に関係なく**、足元の先が空いていれば丸石を置いて進む。標的が1ブロック下までなら「同じ高さ」とみなす。
  すでに標的まで歩ける完全な経路がある間は置かない (むだな橋を作らない)。
- **村人も標的**にして、掘る・橋をかける・柱を積む (`approachVillagers`, 初期値 true)。

### 視線なしの感知
- プレイヤーは今までも視線なしで標的になっていた。**村人は視線が必要で、範囲も16ブロックだけだった**ので、視線なし・索敵範囲 (follow range、初期は64) 全体に変えた。
- 標的を見失った (バニラの標的ゴールは、見えなくなると標的を外す) モブは、0.5秒ではなく **0.2秒ごと**に探し直す。
- ピグリンの頭脳にも、村人の標的を書き込む。

### クリーパー
- 壁を意図して爆破するのは、次の条件が**すべて**そろったときだけ。
  1. 標的が生存モードの**プレイヤー**で、`creeperBreachPlayerDist` (初期16ブロック) 以内にいる。村人だけ・誰もいないときは、意図的には爆発しない。
  2. クリーパーとプレイヤーを結ぶ直線上に、クリーパーから `creeperBreachWallDist` (初期4ブロック) 以内の固いブロックがある (視線の有無は問わない)。
  3. その状態が `obstructedCreeperExpTicks` (初期60ティック=3秒) 続いた。
  4. 爆風がモノリスコアの保護チャンクに届かない (`creeperBreachRespectsMonolith`, 初期値 true)。爆風の半径はそのクリーパーの `ExplosionRadius` (帯電は2倍) で判定し、保護チャンクの可能性があれば爆発しない。半径64超の爆発は安全側で爆発させない。
- 旧: 標的が64ブロック以内にいて壁際なら、プレイヤーが近くにいなくても爆発した (旧設定 `breachingDist` は使わなくなった)。
- 今までどおり: プレイヤーとの距離が `creeperExplodeDist` (6) 未満、またはプレイヤーの真上にいるときは点火する。
- 判定は4ティックに1回 (毎ティックのレイ判定は重いため)。

### スケルトン (剣の構え `SkeletonMeleeStance` を作り直し)
- プレイヤーが **6ブロック以内** (`skeletonFleeDist`): 弓を左手にしまって剣を持ち、**プレイヤーに背中を向けて全速力で逃げる** (`skeletonFleeSpeed`, 初期1.6倍)。プレイヤーから **10ブロック以上** (`skeletonFleeUntilDist`) 離れたら弓に戻って撃つ。
- プレイヤーが **4ブロック以内** (`skeletonHitAndRunDist`) のときだけ、**飛びかかる**: 跳んで近づき、`skeletonLungeReach` (2.4ブロック) 以内で斬り、すぐにプレイヤーのリーチ(3ブロック)の外へ跳び退いて、また走って離れる。次に飛びかかるまで `skeletonLungeCooldownMin`〜`Max` (30〜50ティック) あける。逃げ場がない (追い詰められた) ときは間隔が短くなる。
- 旧設定 `skeletonSwordEnterDist` / `skeletonSwordExitDist` / `skeletonSwordRetreatFactor` は使わなくなった (新しい設定名で初期値が効きます)。
- 後ろに跳ぶ回避 (`SkeletonEvade`) は、この構えの間は動かない。

### 変えていないこと
- モノリスコアの保護 (掘る・置く・TNT・火・クモの巣は、保護チャンクでは止まる)。爆発とプレイヤー操作には干渉しない。
- 上・下掘り、柱積み、TNT、火つけ、エンダーパールゾンビ、レベル連動の速度、ドロップの扱い。
